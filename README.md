# 麦当劳省钱管家（McSave Steward）

> 一句话：把你点的餐自动组合成最省方案——套餐、优惠券、积分、团餐满折一起算，实价为准，确认后才下单。

基于**麦当劳 MCP** 开发的省钱决策 Skill。用户说一句「帮我用最省的方式点：汉堡 + 鸡翅 + 2 份中薯 + 冰淇淋 + 可乐」，它就把单品 / 套餐 / 可用券 / 积分兑券 / 团餐满折放进同一个候选池，枚举出总价最低的合规组合，讲成人话（省了多少、用了哪张券、为什么要拆单），用户确认后才创建订单。

## 这个 Skill 解决什么问题

点麦当劳最费的不是点餐，而是**算不清怎么最省**：

- 优惠组合是「组合爆炸」问题：几十项菜单 × 结构各异的券 × 满折规则，人算不清、大模型也算不准；
- 券有一堆陷阱：一单只能挂一张券、买一送一是专用 SKU、券要车里挂对应商品才生效、到店不会自动套券；
- 套餐的省钱力度通常**压过任何单张券**，只盯着券比价一定会漏掉更省的方案。

省钱管家的解法：**Skill 只做「枚举候选 + 取最小」，一切金额、折扣、积分只认 MCP `calculate-price` 的返回值**——宁可少报优惠，也绝不给你一个到店付不出来的假低价。

## 核心能力

| 能力 | 用户怎么说 | 它怎么做 |
|---|---|---|
| 点单省钱 | 「用最省的方式点」 | 菜单 × 套餐 × 可用券全候选池枚举，逐组实算比价取最小 |
| 自动领券 | 「把能领的券都领了」 | 调 MCP 领全部可领券，避免漏券白亏 |
| 积分兑券 | 「积分怎么用最值」 | 积分换券再抵价（积分不直接抵现） |
| 团餐凑单 | 「家里来 6 个人点什么合适」 | 算一人份 → 乘人数 → 组单 → 自动满折 + 凑单提示 |
| 热量约束 | 「800 大卡以内」 | 调营养库 + 候选组合，给出热量达标的最省方案 |

## 快速开始

### 前置条件
- 麦当劳 MCP Token（open.mcd.cn/mcp，手机号登录 → 控制台 → 激活领取，免费）
- 已安装/可调用的 mcd-mcp（配置见下方示例）

### MCP 配置（示例，Token 用环境变量占位符，切勿提交真实凭证）
```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": { "Authorization": "Bearer ${MCD_MCP_TOKEN}" }
    }
  }
}
```

### 使用示例
1. 「帮我用最省的方式点：巨无霸 + 中薯条 + 中杯可乐」
   → 返回：套餐 vs 单品+券 vs 拆单组合，给出最低价方案 + 拆解说明
2. 「把现在能领的券都领了」
   → 自动领券，返回卡包现状
3. 「800 大卡以内，帮我配一份午饭」
   → 返回热量达标 + 最省的组合
4. 「家里来 6 个朋友，点个团餐」
   → 返回团餐满折最优方案

## 目标用户
- 常吃麦当劳、在乎每一单能省几块的普通顾客；
- 拼单/团餐的发起人（帮一群人把「随便、都行」变成一张能下单的确认单）；
- 想控制热量又要省钱的学生、上班族。
